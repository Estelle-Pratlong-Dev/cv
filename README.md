# CV & Portfolio — Estelle Pratlong

Site personnel regroupant mon **CV de développeuse web**, mon parcours professionnel, mes compétences et une sélection de mes projets.

> 💼 CV / Portfolio personnel

## Le projet

Ce site a été développé afin de disposer d'un support complémentaire à mon CV traditionnel et de présenter plus concrètement mon parcours et mes réalisations.

Il permet notamment de consulter :

- Mon parcours professionnel
- Mes formations
- Mes compétences techniques
- Mes compétences professionnelles
- Mes qualités
- Une sélection de projets
- Les dépôts GitHub et démonstrations associés
- Mon CV au format PDF

## Portfolio

La section Portfolio présente plusieurs projets réalisés à différentes étapes de mon parcours :

- **South-West-Store** — Site e-commerce Symfony
- **Mini ERP** — Application de gestion pour TPE sous Symfony 8
- **Manalex Fleurs** — Site vitrine pour un flower truck
- **Mairie de Gagnières** — Proposition de refonte d'un site municipal
- **Les Petites Mains d'Estelle** — Prototype de site multiservices
- **My Météo** — Application météo réalisée durant ma formation

Selon les projets, le portfolio permet d'accéder à une démonstration en ligne, une démonstration vidéo et/ou au dépôt GitHub correspondant.
